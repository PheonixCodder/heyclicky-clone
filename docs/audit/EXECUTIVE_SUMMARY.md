## 1. Initial Pre-Remediation Audit Verdict (Historical Baseline): `NO-GO` (`DO NOT SHIP`)

**Kursor is NOT ready for production or public release (`NO-GO` / `DO NOT SHIP`).** While the .NET 9.0 desktop solution (`Kursor.sln`, 7 projects, 2,096 C# project source files across 105 namespaces) and the local Node/Hono/SQLite backend worker (`127.0.0.1:8787`, 111 HTTP routes) compile and boot cleanly, independent three-pass testing uncovered **7 Critical (`P0`)** and **44 High (`P1`)** defects across four release-blocking dimensions:

1. **Critical Local Security & Secret Exfiltration (`AUD-C-001` / `AUD-L-001`, `AUD-C-002` / `AUD-L-002`, `AUD-C-003` / `AUD-L-003`, `AUD-J-003`, `AUD-L-008` / `NEW-LM-001`):**
   - The local backend worker at `http://localhost:8787` combines wildcard CORS (`Access-Control-Allow-Origin: *`), automatic local authentication fallback (`middleware/auth.ts:34-88`), and raw upstream API key endpoints (`/v2/dictation/gemini-token`, `/v2/dictation/deepgram-token`, `/agent/realtime/token`). Any arbitrary website visited in the user's browser can read live `GEMINI_API_KEY`, `DEEPGRAM_API_KEY`, and `OPENAI_API_KEY` secrets, read/poison OneBrain memories, or trigger OS-level actions.
   - `/auth/v1/authorize` (`auth.ts:100-126`) is an unvalidated open redirect that mints and appends a 1-year `access_token` and `refresh_token` to any external `redirect_to` URL (`AUD-C-003` / `AUD-L-003`), while `SignInCallbackGuard.Decide` (`SignInCallbackGuard.cs:60-65`) bypasses OAuth `state` verification whenever `isLocalSupabaseBackend` is true.
   - `gunzipSync` in `src/backend/src/middleware/gzip.ts:12-35` has no `maxOutputLength` cap (`AUD-C-002` / `AUD-L-002`), allowing a 67 KB gzip bomb to expand to 68 MB+ synchronously on the main thread.
2. **Broken Core Product Subsystems (`AUD-J-001`, `AUD-E-001`, `AUD-E-002`, `AUD-I-003`, `AUD-D-001`, `AUD-M-001`):**
   - **Autonomous Agents (`clicky-harness.exe`) are 100% non-functional** against the local backend (`AUD-J-001`): all 7 backend routes required by the harness (`/agent/openai/v1/responses`, `/agent/anthropic/v1/messages`, `GET` & `POST /agent/web-search`, `/agent/harness/lab/h1/jobs`, `/agent/harness/lab/h1/probe`, `/mcp/composio`) are missing and return `HTTP 404`.
   - **Screen Ink Notebook markdown corruption (`AUD-I-003`):** Decompilation converted PUA `char` constants `\uE001`/`\uE002` into integer literals in [`ClickyInkParser.cs`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Ink/ClickyInkParser.cs#L1593-L1594), causing `.NET Regex.Replace` to interpret `$"{57345}$1{57346}"` as capture group `$157346` and replace every `**bold**` and `==highlight==` phrase in every Ink note with the literal string `"57345$157346"`.
   - **Warm SAPI TTS permanent queue desynchronization (`AUD-E-001`):** Any 7-second synthesis timeout in [`voice.ts`](file:///C:/dev/heyclicky-clone/src/backend/src/routes/voice.ts#L60-L65) rejects the caller's promise without removing the zombie entry from `warmSynthQueue`, permanently shifting all subsequent TTS responses by one turn (`Caller N+1` receives `Caller N`'s audio).
   - **SSE Stream Disconnect Crash (`AUD-M-001` / `AUD-C-003`):** Aborting a streaming `/brain/turn` request while `tryCallUpstreamLlm` is in flight throws an unhandled `TypeError [ERR_INVALID_STATE]: Controller is already closed` in [`brain.ts`](file:///C:/dev/heyclicky-clone/src/backend/src/routes/brain.ts#L994-L1157).
3. **Host Process Collision & Stale `dist/` Staging (`AUD-A-002`, `AUD-B-003`, `AUD-L-004`):**
   - Kursor retains the upstream `HeyClicky.exe` executable name, `Local\HeyClicky-<SID>-primary` single-instance mutex/MMF, and `heyclicky://` protocol handler (`AUD-B-003`, `AUD-L-004`). On any machine where vendor `HeyClickyApp` is installed, launching Kursor immediately exits (`0x0`) after handing activation to the vendor binary (`PID 20080`).
   - [`scripts/build-dist.ps1`](file:///C:/dev/heyclicky-clone/scripts/build-dist.ps1#L13-L25) copies `Debug` DLLs on top of vendor binaries without `dotnet publish`, leaving `dist/kursor-desktop/` with a mixed Authenticode signature state (`HeyClicky.exe` signed by `CN="Humansongs, Inc"`, 7 rebuilt `HeyClicky*.dll` unsigned, `AUD-A-002`, `AUD-B-005`, `AUD-L-007`).
4. **Legal/IP Provenance & Live Upstream Telemetry (`AUD-B-001`, `AUD-B-002`, `AUD-B-005`):**
   - The repository ships vendor Authenticode-signed `CN="Humansongs, Inc"` binaries (`HeyClicky.exe`, `clicky-harness.exe`, `ClickyBrowserHost.exe`, `WebView2Loader.dll` in `dist/kursor-desktop/`, `AUD-B-005`) and decompiled proprietary source (`AUD-B-002`, `AUD-B-005`), while [`AssemblyInfo.cs`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.App/Properties/AssemblyInfo.cs#L15-L17) embeds live Sentry (`SendDefaultPii = true`), PostHog, and GitHub release feed credentials (`AUD-B-002`).

## 4. Product-Quality Lens (§3 Audit Criteria) & Regressions vs. `reference/decompiled/`

### 4.1 Decompilation & Re-Engineering Regressions vs. `reference/decompiled/`
Comparing `src/desktop/` against the original decompiled assemblies in `reference/decompiled/` and native binaries in `src/desktop/native/` revealed five concrete regressions introduced during decompilation or build-repair:

1. **Screen Ink Bold & Highlight Text Corruption (`AUD-I-003`):**
   - In [`ClickyInkParser.cs:1593-1594`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Ink/ClickyInkParser.cs#L1593-L1594) and [`line 1619`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Ink/ClickyInkParser.cs#L1619), ILSpy decompiled `const char` Private Use Area sentinels (`'\uE000'`, `'\uE001'`, `'\uE002'`) inside interpolated replacement strings as integer literals (`$"{57345}$1{57346}"`). Because `.NET Regex.Replace` parses `$1` followed by digits `57346` as capture group `$157346`, every `**bold**` and `==highlight==` span in every Ink note renders as the literal string `"57345$157346"`.
2. **Hardcoded `DeveloperFlags.FullAgentActivity` Getter (`AUD-K-003`):**
   - In [`DeveloperFlags.cs:14`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Configuration/DeveloperFlags.cs#L14), `FullAgentActivity.get` was decompiled as `get => false;` while `set` writes `"full_agent_activity"` to `DeveloperFlags.json`. Toggling `"Full Agent Activity"` in Settings writes to disk, but the UI checkbox snaps back to `false` and the runtime flag never activates.
3. **Broken `System.Text.Json` Source-Generated Contexts (`AUD-A-003`):**
   - Decompiled init-only/private setters in `BrainJsonContext`, `AgentJsonContext`, `ClickyInkNoteJsonContext`, `ProactiveJsonContext`, `RoutineJsonContext`, and `NotebookV2JsonContext` trigger 6 `SYSLIB1032` warnings where source-generated deserialization silently skips properties unless reflection fallback intervenes.
4. **Compiler-Generated State Machine `NotSupportedException` Stubs (`AUD-K-006`):**
   - Four decompiled iterator classes (`ClickyInkCanvas.<EnumerateWords>d__123`, `Pressable.<WalkAncestors>d__16`, `ClickyNotebookWindow.<DescendantButtons>d__80`, `ClickyNotebookWindow.<FindDescendants>d__81`) retained `void IDisposable.Dispose() { throw new NotSupportedException(); }` in `reference/decompiled/`. While repaired in `src/desktop/`, the unpatched vendor `HeyClicky.exe` in `src/desktop/native/` still ships alongside the repo.
5. **Local Backend vs. Native Sidecar Route Divergence (`AUD-J-001`):**
   - `clicky-harness.exe` (`src/desktop/native/clicky-harness.exe`) is a precompiled Bun/TypeScript binary expecting 7 cloud Worker routes (`/agent/openai/v1/responses`, `/agent/anthropic/v1/messages`, `/agent/web-search`, `/agent/harness/lab/h1/*`, `/mcp/composio`). None of those 7 routes were implemented in `src/backend/src/routes/agent.ts`.

### 4.2 Wait-Moment UX & End-to-End Turn Latency
- **Synchronous Vision Layout Analysis Freezes All Traffic (`AUD-D-002`):** When a user triggers Clicky with a screenshot, `analyzeScreenLayout()` in [`brain.ts:568-633`](file:///C:/dev/heyclicky-clone/src/backend/src/routes/brain.ts#L568-L633) runs pure-JS pixel decoding and connected-component passes synchronously on the main Node.js thread before the SSE stream yields its first event. On a `3840×2160` screenshot (`8.29 MP`), the event loop blocks for **`2,010–6,940 ms`**, stalling concurrent TTS, heartbeat, and UI requests.
- **`force_local_fallback` Still Blocks on Upstream Network Timeouts (`AUD-M-003`):** Passing `force_local_fallback: true` to `/brain/turn` still executes `generateBrainPlan()` against Gemini/OpenRouter (`p50 = 3,652 ms` with live keys vs. `4.91 ms` when short-circuited).
- **Warm SAPI TTS First-Audio Latency (`WS-E`, `WS-M`):** Warm PowerShell `System.Speech` synthesis achieves **`p50 = 197–214 ms`** (`p95 = 247 ms`) for short utterances, and auto-recovers in `794 ms` if `powershell.exe` is killed, but any single 7-second timeout permanently breaks turn ordering (`AUD-E-001`).

### 4.3 Drawing Visual Quality & Screen Layout Accuracy
