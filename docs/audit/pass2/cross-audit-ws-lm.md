### `ID: NEW-LM-001` — `ClickyBrowserBridge` Turn-Wide `uploadAnswers[task]` Cache Allows Bait-and-Switch File & Site Exfiltration After Single Approval, Strips Directory Paths from Approval Cards, and `BrowserUploads.IsSecretFileName` Misses `.db`/`.sqlite`/`.pfx`/`.kdbx` Files
- **Severity**: `HIGH` (`P1`)
- **Workstream**: `WS-L` (Security, Privacy & Data Handling)
- **Component**: [`ClickyBrowserBridge.cs:1088,1173-1300`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/ClickyBrowserBridge.cs#L1173-L1300), [`BrowserUploads.cs:13-21,137-141,365-468`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/BrowserUploads.cs#L365-L468)
- **Description**:
  Four compounding flaws exist in the browser agent file-upload security boundary:
  1. **Turn-wide `uploadAnswers[task]` cache ignores approved files and target site**: In [`ClickyBrowserBridge.UploadAnswerAsync`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/ClickyBrowserBridge.cs#L1173-L1193), once the user clicks "Yes" on an approval card (e.g., via `upload_approval` for `files: ["notes.txt"]` on `trusted.com`, or even an empty `files` list), `uploadAnswers[task] = UploadApprovalAnswer.Allowed` is cached keyed **solely by `task` (`thread + "/" + turn`)**. When [`PrepareUploadsAsync`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/ClickyBrowserBridge.cs#L1280-L1300) runs on a subsequent `upload` or `batch` call in the same turn, `UploadAnswerAsync` (`lines 1175-1180`) immediately returns the cached `UploadApprovalAnswer.Allowed` without checking whether the actual file paths (`usersFiles`) or target website (`Site`) match what the user approved—allowing a prompt-injected agent to exfiltrate up to 10 arbitrary files (100 MB) to an attacker-controlled tab.
  2. **Directory stripping & multi-site `batch` spoofing**: `PrepareUploadsAsync` ([`line 1286`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/ClickyBrowserBridge.cs#L1286)) strips directory paths via `Path.GetFileName(f.Path)` before showing the approval card and passes only `usersFiles[0].Site` (`line 1287`) even when a `batch` call uploads files across multiple tabs/domains.
  3. **Default-allow when `customApprove` is null**: `PerformAsync` ([`line 1088`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/ClickyBrowserBridge.cs#L1088)) evaluates `bool flag5 = customApprove?.Invoke(title) ?? true;`, defaulting to `true` whenever `customApprove` is not wired.
  4. **Incomplete secret-file blocklist**: [`BrowserUploads.IsSecretFileName`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/BrowserUploads.cs#L365-L389) blocks `.env*`, `.pem`, `.key`, `.netrc`, `_netrc`, `.git-credentials`, `.npmrc`, `.pypirc`, and `.pgpass`, but does **not** block `.db`, `.sqlite`, `.db-wal` (allowing upload of `C:\dev\heyclicky-clone\src\backend\data\kursor.db`, which contains unencrypted base64 screenshots, OneBrain memory, and session tokens), `.pfx`, `.p12`, `.kdbx`, `.rdp`, `.ovpn`, or SSH keys (`id_rsa`, `id_ed25519`) outside `.ssh`.
- **Reproduction Steps**:
  1. Inspect [`ClickyBrowserBridge.cs:1173-1300`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/ClickyBrowserBridge.cs#L1173-L1300) and [`BrowserUploads.cs:365-468`](file:///C:/dev/heyclicky-clone/src/desktop/Kursor.Core/HeyClicky.Core.Browser/BrowserUploads.cs#L365-L468).
  2. Trace `AskForUploadsUpFrontAsync` (`files: ["harmless.txt"]`) followed by `PrepareUploadsAsync` (`paths: ["C:\\dev\\heyclicky-clone\\src\\backend\\data\\kursor.db"]` on an external tab) within the same turn.

  - **Observed**: `uploadAnswers[task]` grants blanket approval for any file and any site for the rest of the turn, and `kursor.db` passes `BrowserUploads.ValidatedPaths`.
  - **Expected**: Bind upload approvals to the exact canonical resolved file paths and target site (`(task, site, canonicalPath)`), default `customApprove` to `false`, and block `.db`, `.sqlite`, `.db-wal`, `.pfx`, `.p12`, `.kdbx`, `.rdp`, `.ovpn`, `id_rsa`, and `id_ed25519` in `BrowserUploads.IsSecretFileName`.
